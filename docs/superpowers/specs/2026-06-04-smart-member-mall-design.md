# 智能会员商城系统设计说明

## 1. 项目概述

### 1.1 项目名称

智能会员商城系统

### 1.2 产品定位

面向社区团购、会员超市和实体门店线上化场景的一体化微信小程序商城系统。系统以会员运营为核心，兼顾商品交易、活动营销、订单履约和后台运营效率，首版采用单店单仓模型，支持多自提点和快递到家双履约模式。

### 1.3 本次交付目标

本次交付聚焦“运营增强版可跑骨架”，目标是同时产出产品与技术文档，并生成一个可启动、可继续扩展的项目主干，覆盖以下能力：

- UniApp 用户端骨架
- Vue 3 管理后台骨架
- NestJS REST API 骨架
- MySQL / Redis / JWT 架构预留
- 商品、会员、购物车、订单、优惠券、拼团、秒杀、签到等核心模块边界
- 云部署与后续微信支付接入预留

### 1.4 已确认的业务前提

- 交付级别：运营增强版
- 交付深度：可跑骨架
- 履约模式：快递到家 + 自提
- 组织模型：单店单仓 + 多自提点
- 主营场景：会员超市 / 社区团购
- 支付策略：本次不接正式支付，先保留下单主链路

## 3. 架构设计

### 3.1 总体架构

系统采用前后端分离的模块化单体架构：

1. `apps/mobile`：UniApp + Vue 3 + Pinia 用户端
2. `apps/admin`：Vue 3 + Vite + Pinia 管理后台
3. `apps/api`：NestJS 模块化单体 API 服务
4. `packages/shared`：共享类型、枚举、接口与演示数据

### 3.2 选择 NestJS 模块化单体的原因

- 对首版交付最友好，开发速度与结构清晰度平衡较好
- 便于做 RBAC、DTO、Guard、拦截器和统一响应
- 后续接入支付、分销、AI 时可按模块平滑扩展
- 复杂度显著低于微服务，适合首版快速落地

## 4. 业务模块设计

### 4.1 用户与会员

用户支持微信授权登录、一键登录、手机号登录、验证码登录、密码登录和游客模式。首版骨架以手机号登录和游客浏览为主，微信登录接口位于认证模块预留。

会员体系采用多级模型：

- 普通会员
- 黄金会员
- 铂金会员
- 钻石会员
- 至尊会员

每个等级支持配置：

- 折扣率
- 积分倍率
- 专属商品标记
- 生日礼包
- 充值赠送比例预留
- 优先客服标记

### 4.2 商品与库存

商品模型支持：

- 基础 SPU
- 多 SKU
- 图片、视频、图文详情
- 标签、销量、权重
- 普通价、会员价、活动价
- 单店单仓库存

### 4.3 营销体系

首版实现结构化模块边界：

- 优惠券
- 拼团
- 秒杀
- 签到
- 积分兑换入口预留

营销引擎的结算顺序定义为：

1. 活动价
2. 会员折扣
3. 优惠券抵扣
4. 积分抵扣预留

### 4.4 订单与履约

订单支持两种履约类型：

- `delivery`：快递到家
- `pickup`：门店/团长自提

订单状态统一抽象：

- 待付款
- 待发货
- 待提货
- 待收货
- 已完成
- 已取消
- 售后中

### 4.5 CMS 与首页运营

首页采用楼层式 CMS 编排，支持动态配置：

- 顶部搜索
- 消息通知
- 轮播广告
- 活动公告
- 分类导航
- 猜你喜欢
- 热门商品
- 秒杀楼层
- 新人专区
- 爆款推荐
- 拼团专区
- 会员专享
- 优惠券专区

## 5. 页面与流程设计

### 5.1 用户主流程

`首页 -> 分类/搜索/活动专区 -> 商品详情 -> 购物车/立即购买 -> 结算 -> 订单 -> 履约/售后`

### 5.2 订单结算关键规则

- 结算页自动识别快递与自提模式
- 自提模式必须选择自提点
- 快递模式必须选择收货地址
- 自动匹配可用优惠券
- 自动计算会员折扣
- 不接支付时，首版保留“待付款订单创建”能力

### 5.3 后台运营流程

`首页配置 -> 商品上架 -> 活动配置 -> 会员发券/运营 -> 用户下单 -> 发货/核销 -> 数据复盘`

## 9. 微信支付预留流程

本次不接正式支付，但保留正式接入位置：

1. 用户提交订单
2. 服务端校验库存与价格
3. 生成待支付订单
4. 支付模块生成预支付单
5. 小程序拉起微信支付
6. 支付回调更新订单状态
7. 触发发货/自提流程

首版代码只实现到第 3 步，并为第 4 至第 7 步预留服务接口与状态迁移点。

## 14. 风险与取舍

- 不接正式支付意味着首版无法直接完成真实交易闭环
- 营销模块首版以结构与示例数据为主，不追求完整规则引擎
- 为保证交付节奏，优先实现高价值主链路，再为复杂模块预留扩展点
