# 产品需求文档 PRD

## 一、项目背景

智能会员商城系统用于帮助社区团购与会员超市快速搭建线上销售与会员运营阵地，重点解决“商品售卖、会员沉淀、活动促销、订单履约、自提协同”五类问题。

## 二、目标用户

- 社区团购平台
- 会员超市
- 健康产品门店
- 社区便利店
- 实体门店线上化商家

## 三、核心价值

1. 提升复购：通过会员等级、积分、优惠券、签到持续运营
2. 提高转化：通过首页楼层、秒杀、拼团、会员价拉动下单
3. 提高履约效率：同一套订单模型支持快递与自提
4. 降低上线成本：统一后台配置商品、活动与首页内容

## 五、关键业务规则

- 同一订单只能选择一种履约方式
- 自提订单需要选择自提点
- 活动价优先于普通价
- 会员价与优惠券可叠加，具体规则由营销结算器控制
- 首版允许创建待付款订单，不接正式支付
